### Latest work

#### [Fintech Analytics Decision Room](https://github.com/Victor-Garlet/fintech-analytics-decision-room)

**A falling metric. Several possible causes. What should a payments team do?**

I built an independent fintech case with 10,000 synthetic transfer attempts. I followed the question from source data and metric definitions through dbt models, quality checks and analysis. The result separates an intended price reduction from a fee configuration issue, identifies a settlement problem on one provider route, and recommends a controlled test before changing routing.
